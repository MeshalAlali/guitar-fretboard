# Guitar Fretboard

A polished interactive guitar fretboard visualizer for exploring notes, scales, and chords across a virtual guitar neck.

## Features

- Interactive fretboard with configurable right/left hand orientation
- Note visibility toggles for sharp/flat naming
- Multiple tunings and fret count presets
- Scratch layers for scales and chords
- Layer ordering, opacity, color, and text styling controls
- Built-in major/minor scales and common chord formulas
- Responsive layout for desktop and smaller screens

## Quick start

1. Open `index.html` in your browser.
2. Use the top controls to switch tuning, fret count, and note display.
3. Add scale/chord layers to highlight musical patterns on the fretboard.

## Project structure

- `index.html` — full app and styling
